Puedes visitar la página por medio del siguiente link: https://estudio-verde-educativo.vercel.app/

La página cuenta con:<br>
• Visualización dinámica de mallas académicas universitarias<br>
• Cursos académicos con sección de información, envio de deberes y calificaciones.<br>
• Código especializado en Envio de deberes - Notas para saber si el estudiante envió o no el deber o si está calificado o no el deber<br>
• Cada curso tiene una sección de pizarra, donde el profesor puede escribir su trabajo y al mismo tiempo los estudiantes pueden hacer uso de la pizarra con supervisión del profesor.<br>
• Designación de perfiles de administrador, docentes y estudiantes con permisos respectivos para cada tipo de usuario<br>
• Cada estudiante tiene acceso a 4 pizarras individuales para uso personal.
